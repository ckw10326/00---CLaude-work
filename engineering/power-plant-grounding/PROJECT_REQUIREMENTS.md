## 1. 專案目標

製作一份以權威文獻為依據的「火力發電廠接地系統標準示範報告」，兼顧原理理解、系統分類、施工實務與現場判讀。

讀者應能理解接地為何必要、不同接地系統的用途與安裝方式，並透過施工照片、示意圖及正誤對照，辨識施工是否適當、是否存在明顯缺失，以及還需要哪些資料才能判定合格。

## 3. 預定報告架構

### 第一部分：接地原理

以下為待研究與查證的問題清單，不視為已完成的技術結論：

| 主題 | 應回答的問題 |
| --- | --- |
| 接地目的 | 人身安全、設備保護與系統運作各有哪些需求？ |
| 電流路徑與電位 | 故障電流如何形成回路？大地與接地導體各扮演什麼角色？ |
| 接地與等電位連結 | 兩者有何差異，如何配合？ |
| 接觸電壓、步間電壓、地電位升高 | 危險如何形成？與電廠現場情境有何關係？ |
| 接地電阻與接地阻抗 | 各自代表什麼？如何理解單一電阻數值的判定限制？ |
| 不同接地需求 | 電力故障、防雷、控制與儀表接地需考慮哪些不同條件？ |

各主題採「白話解釋 → 原理示意圖 → 必要工程說明 → 電廠情境 → 來源依據」呈現。公式、數值與簡化模型需交代符號、單位、假設及適用限制。

### 第二部分：電廠接地系統分類

- 優先依功能分類，再對照設備與區域。
- 明確區分接地用途、接地方式與施工材料，不混為同一分類層級。
- 說明各類系統的目的、適用情境、關聯及設計注意事項。
- 實際涵蓋設備與區域待確認，不預設已包含全廠。

### 第三部分：安裝與施工示範

各施工主題原則上包含：

- 適用範圍與前提條件。
- 材料、配置、連接方式及施工步驟。
- 品質控制點與需保留的施工紀錄。
- 施工照片、細部圖或依文獻繪製的示意圖。
- 正確做法、常見缺失及其影響。
- 對應來源、版本、條款或頁碼。

### 第四部分：常見缺失與現場判讀

- 提供正確與錯誤對照，清楚標示應觀察的位置及判讀理由。
- 區分「可由照片確認的現象」與「需要進一步查證的問題」。
- 不將無法辨識、缺少背景或尚無依據的照片直接判定為合格或不合格。
- 說明缺失的原理、可能影響，以及需要進一步確認的資料。

### 第五部分：檢查與驗收

檢查項目依證據類型區分：

1. 目視或照片可確認。
2. 需材料證明、施工紀錄或隱蔽工程紀錄確認。
3. 需現場量測或試驗確認。
4. 需設計計算或系統資料確認。

照片不能單獨證明整套接地系統合格。任何驗收門檻與判定數值，均須核對適用條件及正式依據。

## 4. 權威來源與查證要求

### 4.1 來源選用

- 規範要求：採用適用地區的法規、正式標準及業主規範；須確認版本與適用性。
- 原理解釋：優先採用正式標準的說明、權威工程教材及具公信力機構的技術文件。
- 施工方法與案例：優先採用正式施工文件、機構技術資料及可追溯的工程案例；製造商資料需註明產品與適用限制。
- 網頁摘要、搜尋結果與無來源圖片只能作為查找線索，不作為已核實的規範依據。
- 來源權威性不等同於對本專案必然適用；須同時檢查所在地、業主要求、系統條件與文件版本。

### 4.2 每項重要內容的證據紀錄

至少記錄：

| 欄位 | 要求 |
| --- | --- |
| 來源識別 | 文件名稱、發布機構或作者、標準編號（如有） |
| 版本 | 年份、版次、修訂或勘誤資訊（如適用） |
| 定位 | 條款、頁碼、圖號或表號 |
| 取得方式 | 原始連結或合法取得的本地文件位置 |
| 適用條件 | 地區、設備、系統條件及限制 |
| 支持內容 | 該來源實際支持的敘述或要求 |
| 查證狀態 | 已核對原文／待取得原文／待釐清適用性／來源衝突 |

### 4.3 正確性控制

- 將使用者要求的高度正確性落實為可查核的證據流程，不以「保證絕對正確」取代查證。
- 有來源且適用性確認後，才寫成規範要求。
- 未取得原文核對的內容，不標示為「已確認」。
- 區分強制要求、建議做法、原理解釋與本報告的推導整理。
- 來源衝突、版本差異或適用性不明時，記錄差異並列為待確認，不自行拼接成結論。
- 重要安全判定、公式與數值需額外覆核；如缺少交叉佐證，明確揭露。
- 不虛構引用、條款、照片背景、量測結果或工程案例。

## 5. 圖片與示意圖要求

- 圖片須記錄出處、圖說、適用情境與使用授權狀態。
- 每張施工示範圖應回答：應該怎麼做、看哪裡、依據是什麼、圖像無法證明什麼。
- 自行繪製的圖須標明「依據文獻整理之示意圖」，並附參考來源。
- 示意圖不得冒充標準原圖、真實施工照片或現場驗證證據。
- 不為了湊齊正誤對照而將背景不明的照片定性為錯誤案例。

## 6. 預期成果

1. 專案需求文件（本文件）。
2. 權威來源清單與查證紀錄。
3. 報告詳細大綱及章節對應來源。
4. 原理圖、施工照片及案例素材清單。
5. 包含原理、分類、施工示範、缺失判讀與驗收的報告。
6. 可追溯依據的現場檢查表。

最終報告格式、篇幅及是否另製簡報，待後續確認。

## 7. 分階段執行

1. 確認適用地區、讀者、設備範圍與可用資料。
2. 建立來源清單，確認原文取得方式、版本與適用性。
3. 建立詳細大綱與證據對照，先完成原理章節的研究。
4. 逐項整理系統分類、施工方法及照片案例。
5. 整合檢查與驗收內容，核對引用及技術敘述。
6. 完成報告排版、圖像檢查與整體覆核。

每階段保留未解問題；影響安全判定或適用性的問題未釐清前，不將相關內容定稿。

## 8. 待確認事項

以下尚未獲得使用者確認，不視為既定需求：

- 適用地區：是否以臺灣為主？是否採台電或特定業主規範？
- 主要讀者：施工人員、監造／驗收工程師、設計工程師或主管？
- 設備範圍：全廠或部分系統？候選範圍包括發電機、變壓器、開關場、控制儀表、建築及防雷。
- 使用情境：教育訓練、施工參考、監造檢查或正式工程文件？
- 現有資料：是否有電廠圖說、施工規範、現場照片或既有報告？
- 標準全文取得：有哪些可合法使用的標準、教材或資料庫？
- 最終交付格式、篇幅與技術深度。
- 正式工程用途是否另有專業審查人員與審查流程要求。

## 9. 完成判準

- 報告涵蓋已確認範圍，並依原理、分類、施工、缺失、驗收形成連貫內容。
- 重要敘述、規範要求、公式與數值均可追溯至已核對來源。
- 清楚揭露版本、適用限制、證據不足與待確認內容。
- 圖片與案例具來源、判讀依據，且未超出影像可支持的結論。
- 讀者能辨識目視檢查與量測、計算、紀錄查核的界線。
- 需求的後續變更持續記錄於本文件。
